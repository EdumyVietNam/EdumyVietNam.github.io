Tổng quan khóa học

Giới thiệu chi tiết nội dung, mục tiêu và yêu cầu đầu vào

Khóa học dành cho người mới bắt đầu muốn làm chủ bộ ba nền tảng của lập trình web: HTML để dựng cấu trúc, CSS để hoàn thiện giao diện và JavaScript để tạo nên sự tương tác. Bạn sẽ được học từ con số 0, thực hành qua từng ví dụ minh họa và kết thúc bằng một dự án website hoàn chỉnh.

Toàn bộ bài giảng có kèm tài liệu đọc (PDF/Markdown) tóm tắt nội dung từng chương. Ngoài ra, trợ lý AI của EDUMY giúp bạn giải đáp thắc mắc ngay trong lúc học mà không cần chờ đợi.

Bạn sẽ học được gì?
  • Dựng cấu trúc trang web chuẩn ngữ nghĩa với HTML5
  • Trang trí giao diện chuyên nghiệp với CSS, Flexbox & Grid
  • Lập trình tương tác trang web bằng JavaScript & DOM
  • Thiết kế giao diện responsive hiển thị tốt trên mọi thiết bị
  • Xây dựng hoàn chỉnh một dự án website thực tế
  • Nắm vững tư duy và quy trình phát triển web chuẩn

Yêu cầu khóa học

  • Không cần kinh nghiệm lập trình trước đó
  • Máy tính có trình duyệt web hiện đại
  • Mã nguồn mẫu (VS Code) được cài sẵn trong chương 1

Đối tượng phù hợp

  • Người mới bắt đầu muốn theo đuổi lập trình web
  • Sinh viên CNTT cần nền tảng front-end vững chắc
  • Người muốn chuyển ngành sang phát triển web
