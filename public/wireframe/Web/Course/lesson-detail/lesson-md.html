Tóm tắt chương 4

Ghi chú tổng kết toàn bộ kiến thức JavaScript căn bản đã học trong chương — biến, hàm, mảng, arrow function, destructuring và DOM — giúp bạn ôn tập nhanh trước khi bước vào dự án thực tế.

Tóm tắt chương 4: JavaScript căn bản

Nguyễn Minh Thư Chương 4 · Bài 13/13 6 phút đọc

1. Kiến thức đã học

Trong chương này bạn đã làm quen với các nền tảng của JavaScript — từ khai báo biến đến thao tác DOM. Dưới đây là những điểm quan trọng cần nhớ trước khi sang chương 5.

  • Biến & kiểu dữ liệu: let/const thay cho var, phân biệt number, string, boolean, null, undefined.
  • Hàm: khai báo hàm, tham số, giá trị trả về và phạm vi hoạt động.
  • Mảng & phương thức: map, filter, reduce, forEach.
  • Arrow function & destructuring: cú pháp rút gọn và trích xuất dữ liệu.
  • DOM & sự kiện: chọn phần tử, lắng nghe sự kiện, cập nhật nội dung trang.

2. Arrow function & destructuring

Arrow function là cú pháp rút gọn của hàm, giúp code ngắn gọn hơn và không tự tạo ngữ cảnh this riêng — kế thừa this từ phạm vi bên ngoài. 

// Cách viết cũ
const sum = function (a, b) {
  return a + b;
};

// Arrow function
const sum = (a, b) => a + b;

// Destructuring mảng & object
const [first, second] = [10, 20, 30];
const { name, age } = user;
Tip: Kết hợp destructuring với arrow function để viết callback rất gọn — ví dụ users.map(({ id }) => id).

4. Luyện tập trước khi sang chương 5

  1. Viết lại các ví dụ trong bài giảng bằng arrow function.
  2. Hoàn thành bài tập Đồng hồ đếm ngược (tài liệu PDF).
  3. Thử kết hợp setInterval + DOM để xây một bộ đếm nhỏ.
  4. Đọc lại phần DOM & sự kiện trước khi làm dự án cuối khóa.
