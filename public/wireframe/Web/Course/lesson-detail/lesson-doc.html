2. Yêu cầu chức năng

- Người dùng nhập số phút/giây mong muốn
- Bấm "Bắt đầu" để chạy đếm ngược
- Hiển thị MM:SS, đổi màu khi dưới 10 giây
- Bấm "Tạm dừng" / "Tiếp tục" bất kỳ lúc nào
- Kết thúc: phát thông báo + tự reset

3. Gợi ý kiến thức sử dụng

render(seconds);  // render lên DOM
if (seconds <= 0) clearInterval(timer);
}, 1000);
